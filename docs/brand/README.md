# Marchio OpenStage

Il marchio è **O/S**: le iniziali di *Open/Stage*, con lo slash in gradiente viola→ciano.
Nasce dallo stesso segno già usato nel logotipo testuale (`Open/Stage`) e resta leggibile
anche a 16 px nella versione semplificata.

## Colori e font

- Fondo: `#07070D`
- Gradiente del marchio: `#8B5CF6` → `#22D3EE`
- Punto “live”: `#F472B6` (solo negli usi grandi, non nell'avatar)
- Testi: `#FFFFFF`; testi secondari: `#8A8AA8`
- Font: **Anton** per il marchio, **IBM Plex Mono** per le etichette. Entrambi OFL.

## Regole

- Il gradiente vive **solo** sul marchio e sul filo decorativo: non dietro testi lunghi.
- Non aggiungere ombre pesanti, né il logo Spotify o altri marchi di terzi.
- Sull'avatar Spotify il marchio è centrato e senza testo: il nome profilo è già “OpenStage”.
- La favicon usa solo lo slash: a 16 px le lettere O/S diventano illeggibili.
- Per la copertina playlist usare `openstage-playlist-1000.png` così com'è: il titolo è già
  dentro l'immagine e resta leggibile a 300 px.
